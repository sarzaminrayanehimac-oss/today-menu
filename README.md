# امروز چی بپزم؟ 🍲

یه وب‌اپ ساده‌ی فارسی برای اینکه هر روز نپرسیم «ناهار چی داریم؟»

- **یخچالو نگاه کن:** مواد موجود رو انتخاب کن تا غذاهای ایرانیِ قابل‌پخت و طرز تهیه‌شون (برای ۲ نفر) بیاد.
- **برنامه غذایی هفتگی:** بر اساس سن، قد، وزن و تحرک، کالری روزانه تخمین زده می‌شه و یه برنامه‌ی هفتگی می‌چینه؛ هر وعده قابل تغییره.

## بخش‌ها
خانه (تعداد نفرات)، یخچال، غذاها (شامل منوی رستوران و فست‌فود)، برنامه هفتگی، و درباره.

## اجرا
فقط فایل `index.html` رو توی مرورگر باز کن (برای فونت و انیمیشن سه‌بعدی اینترنت لازمه).
با GitHub Pages هم می‌شه منتشرش کرد: Settings ← Pages ← Branch: main.

## نصب روی گوشی
سایت رو توی مرورگر گوشی باز کن. توی اندروید (کروم) منوی ⋮ ← «Install app» یا «Add to Home screen».
توی آیفون (سافاری) دکمه‌ی Share ← «Add to Home Screen».
تم روشن و تاریک هم با دکمه‌ی بالای صفحه عوض می‌شه.

## نکته‌ی سلامت
کالری با فرمول Mifflin-St Jeor تخمین زده می‌شه و کالری غذاها تقریبیه. حداقل کالری ۱٬۲۰۰ (خانم‌ها) و ۱٬۵۰۰ (آقایون) رعایت می‌شه.
این برنامه جای نظر پزشک یا متخصص تغذیه نیست.
